Automated Web Security Scanner

1. Project Description

The Automated Web Security Scanner is a Python-based cybersecurity project that performs basic security configuration checks on a target website.

The scanner examines whether HTTPS is used, checks selected HTTP security headers, and inspects cookie security attributes. It displays the findings in the terminal and saves the results in a JSON file named scan_report.json.

This project is intended for educational purposes and demonstrates how Python can be used to automate basic website security checks. It is not a complete vulnerability scanner.

2. Project Objectives

Check whether a target website uses HTTPS.

Examine selected HTTP security headers.

Inspect cookie attributes such as Secure, HttpOnly, and SameSite.

Display security findings in the terminal.

Save scan results in JSON format.

Understand basic web security concepts and Python automation.

3. Technologies Used

Python: Main programming language.

Requests: Sends HTTP requests and receives website responses.

JSON: Stores scan results in a structured format.

Python Standard Library: Supports URL handling, text processing, and other basic operations.

4. Security Checks Performed

The scanner checks for the presence of the following HTTP security headers:

Strict-Transport-Security (HSTS)

Content-Security-Policy (CSP)

X-Content-Type-Options

X-Frame-Options

Referrer-Policy

Permissions-Policy

It also examines these cookie security attributes when cookies are available:

Secure

HttpOnly

SameSite

The presence of a header or cookie attribute does not automatically guarantee that a website is secure. Findings should be reviewed in context.

5. Dataset / Input Source

This project does not require a separate static dataset. It uses the live HTTP response from the target website as its input.

Input: A website URL that the user owns or is authorized to test.

Output: Security check results displayed in the terminal and saved to scan_report.json.

7. Installation and Setup

Step 1: Install Python

Install Python 3 if it is not already installed. Make sure Python is accessible from your terminal.

Check the installation:

python --version

Step 2: Open the Project Folder

Open Command Prompt and navigate to the folder containing the project files.

Example:

cd path\to\your\project

Replace the example path with your actual project folder path.

Step 3: Install Dependencies

Run:

python -m pip install -r requirements.txt

This installs the required external Python libraries.

8. How to Run the Scanner

Run the Python program from the project folder:

python scanner.py

If your Python file has a different name, replace scanner.py with the actual filename.

Follow the program's prompts, if any, and provide the target URL in the format expected by your code.

After the scan, review the terminal output and check whether scan_report.json has been created or updated.

10. Expected Output

The scanner reports the results of its configured checks, including HTTPS usage, selected security headers, and cookie attributes.

Actual findings depend on the target website's response. The generated JSON report provides a structured record of the results for later review.

11. Limitations

The scanner performs only predefined security checks.

It does not detect every web application vulnerability.

It does not replace a professional security audit or penetration test.

Some websites may block automated requests or require authentication.

Missing headers should be investigated rather than automatically treated as proof of a vulnerability.

12. Ethical Use

Use this scanner only on websites you own or have explicit permission to assess. Do not use it to perform unauthorized security testing.
